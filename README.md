# My-Huya-CK

![Version](https://img.shields.io/badge/version-1.1.0-blue)
![Python](https://img.shields.io/badge/Python-3.10%2B-blue)
![Platform](https://img.shields.io/badge/platform-Windows-lightgrey)
![License](https://img.shields.io/badge/license-MIT-green)

虎牙单房间 Windows 本机场控工具：用持久化 Chromium 挂住一个虎牙直播间，通过本机网页控制台配置规则，自动从直播间输入框发送欢迎、感谢和文本轮播。

> **声明**：本项目非虎牙官方项目，与虎牙直播无隶属、授权或合作关系。仅供学习交流，请勿用于违规用途。

## ✨ 功能特性

### 自动互动

- **进场欢迎**：按贵族等级、消费等级和守护状态筛选；同一人可配置冷却时间，避免重复欢迎（默认 5 分钟）。
- **礼物感谢**：支持"本包合计金额"与"单件金额"双重门槛；连击礼物按静默窗口自动合并感谢；0 元礼物只记录不感谢。
- **守护感谢**：识别开通/升级及初爱守护、超级守护、至尊守护。
- **超粉感谢**：识别普通超粉与超粉PLUS。
- **贵族感谢**：识别开通/升级、续费、贵族名称和月份。
- **昵称映射**：可为指定 UID 配置自定义称呼，弹幕输出优先使用自定义昵称。
- **文本轮播**：导入 TXT（小说、话术、台词皆可）拆条连播，支持循环回卷，进度持久化。

### 控制与安全

- **统一弹幕队列**：三级优先级（指令反馈 > 欢迎/感谢 > 轮播），发送成功点击后才开始计算下一条 CD；失败不重试。
- **LU 远程场控**：在弹幕中发送指令即可远程控制，白名单严格受分模块权限限制。
- **当前账号与白名单**：只有当前账号或启用的白名单用户可进入授权记录，普通观众不保存弹幕正文。
- **弹幕识别**：通过 1400 TAF 读取 UID、昵称和正文，为远程指令与趣味互动提供输入。
- **稳定性**：登录换页恢复、TAF 存活检测、自动重新进房、日志轮转。

> 生产事件只来自虎牙页面 TAF；WebSocket/JCE 仅用于 `validation/` 中发现和分析新消息，不参与自动发送，也没有备用链路。

## 🚀 快速开始

### 环境要求

- Windows 10 及以上
- [Python](https://www.python.org/downloads/) 3.10 或更高版本（加入 PATH）

### 安装与启动

1. 双击 `run.bat`。首次运行会自动创建 `.venv`、安装依赖并下载专用 Chromium。
2. 打开 <http://127.0.0.1:8787/>，点击"打开浏览器登录"完成虎牙登录。
3. 填写房间号和规则，打开需要的功能。
4. 最后打开"允许发送"并启动场控。

首次运行使用内置安全默认值：空房间、所有自动功能关闭。本机设置写入不受 Git 跟踪的 `config/app.json`。

> 网页中的"停止"只停止挂房；关闭启动场控的命令行窗口才会退出程序。

## 📖 使用说明

### 欢迎与感谢规则

| 功能 | 触发条件 | 默认文案 |
| --- | --- | --- |
| 进场欢迎 | 贵族和消费等级同时达标，或用户有守护 | 在网页中配置 |
| 礼物感谢 | 合计金额及单件金额都达到门槛 | `感谢{nick}送的{count}个{item_name}` |
| 守护感谢 | 6540 同时具备身份、昵称、动作和已知守护名 | `感谢{nick}为主播{action}{guard_name}!` |
| 超粉感谢 | 10079 普通超粉或 2001231 超粉PLUS | `感谢{nick}为主播开通{superfan_name}!` |
| 贵族感谢 | 1001 包含有效动作、贵族名和当前房间信息 | `感谢{nick}为主播{action}{noble_name}{months}个月!` |

- **金额**：在网页中按元填写，支持小数（如 `1.2` 元）。单件金额 = 本包合计金额 ÷ 数量。
- **礼物连击合并**：同一人连送同一种礼物，静默一段时间（默认 3 秒）后合并成一条感谢，数量和金额按合计；窗口最长 8 秒强制结算。设为 0 秒则不合并，每包立刻判断。
- **欢迎冷却**：同一人从决定欢迎时起算，冷却时间内（默认 5 分钟）不重复欢迎；设为 0 表示每次进场都欢迎。

### 远程指令（LU）

在弹幕中发送 `LU 开启/关闭 发送/欢迎/感谢` 即可远程控制。空格可省略，LU 不区分大小写，必须整条弹幕完整匹配。"感谢"包括礼物、守护、超粉和贵族感谢。

### 文本轮播

在"趣味互动"分页上传本机 UTF-8 TXT（≤5 MiB），选择当前文本并配置每条字数（15～28）和发送间隔（≥3 秒）。发送走统一弹幕队列的最低优先级，欢迎和感谢总是先发。

- 支持循环播放：播完最后一条回卷到第一条继续。
- 一次只有一条在途；发送失败不重试，顺序推进到下一条。
- 进度持久化，重启程序后保留进度但保持暂停，不会无人值守自动刷屏。
- 修改每条字数或更换文本会重置进度。
- 上传、删除和选择文本只能在 WebUI 完成；删除需二次确认，播放中的文本不能删。
- 文本正文保存在 `data/novels/`（不进 Git），日志只记录条号和 ≤30 字预览。

轮播指令（当前账号，或白名单勾选"允许控制轮播"的用户）：

| 指令 | 行为 |
| --- | --- |
| `LU 轮播 开始` | 从第一条重新播放 |
| `LU 轮播 暂停` | 暂停并保留进度 |
| `LU 轮播 继续` | 从保存位置继续 |
| `LU 轮播 停止` | 停止并把进度归零 |
| `LU 轮播 下一条` | 立即发送当前待播条 |
| `LU 轮播 状态` | 弹幕反馈文本名、状态和进度 |

旧关键词 `LU 小说 *` 继续兼容。`LU 关闭 发送` 会同时暂停轮播并清除在途条，重新开启发送后轮播不自动恢复。

## ⚙️ 配置说明

所有配置通过 WebUI（<http://127.0.0.1:8787/>）完成，保存在 `config/app.json`（不进 Git）。完整默认值见 [`config/app.example.json`](config/app.example.json)。

- 弹幕文本建议不超过 28 字（虎牙输入框上限 30）：超长仅记日志提示，不拦截、不截断。
- 页面 TAF 当前订阅 `1400`、`1001`、`6110`、`6501`、`6540`、`10079` 和 `2001231`。
- 远程控制没有独立总开关，会随挂房与 1400 监听运行。

## ❓ 常见问题

日志位于 `logs/huya_ck.log`，会自动轮转。普通用户进场和未授权弹幕不会逐条打印。

| 现象 | 排查 |
| --- | --- |
| 有"入队"但没有"已发送" | 检查"允许发送"、登录状态和页面输入框；需要观察页面时启用"显示直播间窗口" |
| 发送按钮超时 | 该条已从队列取出但不会启动 CD，也不会自动重试；下一条仍可继续尝试 |
| 弹幕超长提示 | 模板或轮播条目超过 28 字仅记日志，仍会尝试发送；如失败可缩短模板或减小每条字数 |
| 轮播不进行 | 检查趣味互动总开关、轮播模块开关和是否选择了文本；改过每条字数则进度已归零 |
| 礼物未感谢 | 检查是否为 0 元、合计金额不足或单件金额不足 |
| 非礼物事件未感谢 | 查看对应 URI 的诊断文本和字段键名，字段不完整时程序会安全忽略 |

> **隐私提示**：日志、登录 Profile、抓包和 `data/novels/` 可能包含房间号、昵称、账号状态或小说正文，不要公开完整内容。相关本地目录已由 `.gitignore` 排除。

## 🔧 开发指南

项目脚本一览（均双击或命令行运行，自动定位项目根目录）：

| 脚本 | 用途 |
| --- | --- |
| `run.bat` | 唯一入口：查找/自动安装 Python 3.10+，准备 `.venv` 与专用 Chromium，启动场控 |
| `tests.bat` | 跑 `tests/` 全量单元测试（需先 `run.bat` 建好环境） |
| `release-check.bat` | 发布前检查：测试 + 默认配置/WebUI 产物/敏感目录校验 + Git 状态 |
| `ensure_env.py` | 环境准备（幂等）：建 `.venv`、装依赖、下载 Chromium；`--force` 全部重装 |
| `release_check.py` | 发布检查的只读校验逻辑，由 release-check.bat 调用 |
| `validation/run.bat` | 抓包分析探针菜单（仅研发用，验证协议用后即删） |

修改 WebUI 需要 Node.js，并必须同时更新源码和构建产物：

```bat
cd web-src
npm ci
npm run build
```
