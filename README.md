# My-Huya-CK

虎牙单房间 Windows 本机场控工具。程序用持久化 Chromium 挂一个虎牙直播间，通过网页控制台配置规则，并从直播间输入框自动发送欢迎、感谢或文本轮播。

> 非虎牙官方项目，与虎牙直播无隶属、授权或合作关系。

生产事件只来自虎牙页面 TAF；WebSocket/JCE 仅用于 `validation/` 中发现和分析新消息，不参与自动发送，也没有备用链路。

## 当前功能

- 进场欢迎：按贵族等级、消费等级和守护状态筛选。
- 礼物感谢：同时支持“本包合计金额”和“单件金额”门槛；0 元礼物只记录不感谢。
- 守护感谢：识别开通/升级及初爱守护、超级守护、至尊守护。
- 超粉感谢：识别普通超粉与超粉PLUS，产品文案统一为“开通”。
- 贵族感谢：识别开通/升级、续费、贵族名称和月份。
- 统一弹幕队列：三级优先级（指令反馈 > 欢迎/感谢 > 轮播），发送按钮成功点击后才开始计算下一条 CD；失败不重试。
- 弹幕文本上限 28 字（虎牙输入框上限 30）：超长拒绝入队，不做截断。
- 弹幕识别基础：通过 1400 TAF 读取 UID、昵称和正文，为远程指令与趣味互动提供输入。
- 当前账号与白名单：只有当前账号或启用的白名单用户可进入授权记录；普通观众只显示 UID/昵称候选，不保存正文。
- LU 远程场控：支持开启或关闭发送、欢迎和聚合感谢；白名单严格受分模块权限限制。
- 趣味互动·文本轮播：本机导入 TXT（小说、话术、台词皆可）拆条连播，支持循环回卷，WebUI 与 LU 指令双通道控制，进度持久化。
- 登录换页恢复、TAF 存活检测、自动重新进房和日志轮转。

## 快速开始

1. 安装 Python 3.10 或更高版本，并加入 PATH。
2. 双击 `run.bat`。首次运行会自动创建环境、安装依赖并下载专用 Chromium。
3. 打开 <http://127.0.0.1:8787/>，点击“打开浏览器登录”完成虎牙登录。
4. 填写房间号和规则，打开需要的功能；最后再打开“允许发送”并启动场控。

网页中的“停止”只停止挂房；关闭启动场控的命令行窗口才会退出程序。首次运行使用内置的安全默认值：空房间、所有自动功能关闭。本机设置写入不受 Git 跟踪的 `config/app.json`。

## 规则速查

| 功能 | 触发条件 | 默认文案 |
| --- | --- | --- |
| 进场欢迎 | 贵族和消费等级同时达标，或用户有守护 | 在网页中配置 |
| 礼物感谢 | 合计金额及单件金额都达到门槛 | `感谢{nick}送的{count}个{item_name}` |
| 守护感谢 | 6540 同时具备身份、昵称、动作和已知守护名 | `感谢{nick}为主播{action}{guard_name}!` |
| 超粉感谢 | 10079 普通超粉或 2001231 超粉PLUS | `感谢{nick}为主播开通{superfan_name}!` |
| 贵族感谢 | 1001 包含有效动作、贵族名和当前房间信息 | `感谢{nick}为主播{action}{noble_name}{months}个月!` |

LU 一级指令：`LU 开启/关闭 发送/欢迎/感谢`，空格可省略，LU 不区分大小写；“感谢”包括礼物、守护、超粉和贵族感谢。

金额在网页中按元填写，支持小数，例如 `1.2` 元。单件金额按“本包合计金额 ÷ 数量”计算，因此磁铁一类数量经过倍率换算后仍会保留实际数量。

页面 TAF 当前订阅 `1400`、`1001`、`6110`、`6501`、`6540`、`10079` 和 `2001231`。远程控制没有独立总开关，会随挂房与 1400 监听运行。

## 文本轮播

在“趣味互动”分页上传本机 UTF-8 TXT（≤5 MiB）——小说、话术、台词都可以，选择当前文本并配置每条字数（15～28）和发送间隔（≥3 秒）。发送走统一弹幕队列的最低优先级，欢迎和感谢总是先发；实际间隔取全局 CD 与轮播间隔的较大值。

- 支持循环播放：播完最后一条回卷到第一条继续，适合话术库轮播。
- 一次只有一条在途；发送失败不重试，顺序推进到下一条。
- 进度持久化，重启程序后保留进度但保持暂停，不会无人值守自动刷屏。
- 修改每条字数或更换文本会重置进度，从第一条重新开始。
- 上传、删除和选择文本只能在 WebUI 完成；删除需二次确认，播放中的文本不能删。
- 文本正文保存在 `data/novels/`（不进 Git），日志只记录条号和 ≤30 字预览。

指令（当前账号，或白名单勾选“允许控制轮播”的用户）：

| 指令 | 行为 |
| --- | --- |
| `LU 轮播 开始` | 从第一条重新播放 |
| `LU 轮播 暂停` | 暂停并保留进度 |
| `LU 轮播 继续` | 从保存位置继续 |
| `LU 轮播 停止` | 停止并把进度归零 |
| `LU 轮播 下一条` | 立即发送当前待播条 |
| `LU 轮播 状态` | 弹幕反馈文本名、状态和进度 |

旧关键词 `LU 小说 *` 继续兼容。解析规则与一级指令一致：LU 不区分大小写、空格可省略、允许一个结尾 `！!。.`、必须整条弹幕完整匹配。`LU 关闭 发送` 会同时暂停轮播并清除在途条，重新开启发送后轮播不自动恢复。

## 日志与排查

日志位于 `logs/huya_ck.log`，会自动轮转。普通用户进场和未授权弹幕不会逐条打印。

- 有“入队”但没有“已发送”：检查“允许发送”、登录状态和页面输入框；需要观察页面时启用“显示直播间窗口”。
- 发送按钮超时：该条已从队列取出但不会启动 CD，也不会自动重试；下一条仍可继续尝试。
- “弹幕超长拒绝入队”：欢迎/感谢模板或轮播条目超过 28 字，请缩短模板或减小每条字数。
- 轮播不进行：检查趣味互动总开关、轮播模块开关和是否选择了文本；改过每条字数则进度已归零。
- 礼物未感谢：检查是否为 0 元、合计金额不足或单件金额不足。
- 非礼物事件未感谢：查看对应 URI 的诊断文本和字段键名，字段不完整时程序会安全忽略。

日志、登录 Profile、抓包和 `data/novels/` 可能包含房间号、昵称、账号状态或小说正文，不要公开完整内容。相关本地目录已由 `.gitignore` 排除。
