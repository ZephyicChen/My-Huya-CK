# 消息字段合同

产品只把页面 TAF 回调转换为领域事件。现场抓到的 WebSocket/JCE 只用于确认 URI 和业务语义，不是运行时来源。

| 领域事件 | URI | 当前状态 |
| --- | ---: | --- |
| `enter` | 6110 | 页面 TAF 已验证，可用于进场欢迎 |
| `gift` | 6501 | 页面 TAF 已验证，可用于礼物感谢 |
| `guard_open` | 6540 | 业务语义已验证；TAF 候选字段需继续实证，严格字段不足时忽略 |
| `noble_open` | 1001 | 业务字段已由样本确认；TAF 监听已接入，需继续现场复验 |
| `superfan_open` | 10079 / 2001231 | 普通/PLUS 语义已确认；TAF 监听已接入，需继续现场复验 |
