# 弹幕解析

## 事件来源

产品在虎牙页面的 `TTP.ready` 业务通道中订阅 URI `1400`，不使用 WebSocket 业务兜底，也不从 DOM 文案识别弹幕。

## 字段合同

页面桥接只提取具名字段，并转换为 `chat_message`：

| 领域字段 | 页面候选字段 | 约束 |
| --- | --- | --- |
| `uid` | `lSenderUid`、`lUid`、`lUserId` 等 | 必须为大于 0 的整数；Python 保留大整数精度 |
| `nick` | `sSenderNick`、`sNickName`、`sUserNick` 等 | 必须非空 |
| `content` | `sContent`、`sMessage`、`sMsg` 等 | 必须非空 |
| `room_id` | `lRoomId`、`lPid` | 可选 |
| `show_mode` | `iShowMode` | 可选 |
| `message_id` | `lMsgId`、`sMsgId` 等 | 可选；优先用于事件去重 |

系统消息昵称会被拒绝。字段不完整时不生成事件，诊断最多每 60 秒打印一次，并且只包含字段名，不包含候选正文。

## 权限与隐私

- 所有有效用户弹幕都会更新最近发言人的 UID、昵称和最后出现时间，最多保留 100 人。
- 未授权用户的正文不写日志、不进入授权记录，也不送入后续指令处理。
- 当前账号和启用的白名单用户属于授权输入，正文最多保留最近 200 条在内存中，进程退出即消失。
- 程序刚刚成功发送的同文弹幕会在短时间内被视为自身输出，不作为授权输入处理。

当前版本在授权输入上实现严格的 `LU 开启/关闭 发送/欢迎/感谢` 一级指令。只有整条弹幕匹配时才执行；“感谢”映射礼物、守护、超粉和贵族感谢，白名单只修改明确获权的子模块。趣味互动规则尚未接入。
