# 贵族进场（URI 6110）

## TAF 业务结构

网页贵族组件使用 `TTP.addTafListener("6110")` 订阅 `VipEnterBanner`。产品在 `platform/official_taf.py` 读取：

| 输出 | 官方字段 |
| --- | --- |
| `uid` | `lUid` |
| `nick` | `sNickName` |
| `room_uid` | `lPid` |
| `noble_name` | `tNobleInfo.sNobleName` |
| `noble_level` | `tNobleInfo.iNobleLevel` |
| `guard_level` | `tGuardInfo.iGuardLevel` |
| `guard_text` | `tGuardInfo.sEnterText / sNewAttr / sAttr` |
| `consume_level` | `tDecorationInfo.vDecorationPrefix` 中 appId 11200 的徽章数据 |

消费徽章是 TAF 结构 `tDecorationInfo.vDecorationPrefix` 中的字节字段，产品只在该已解码结构内部读取其徽章值。WebSocket 原始包的 JCE tag 路径属于验证资料，见 `validation/docs/`，不得作为业务备用入口。

`guard_text` 非空或 `guard_uid != 0` 时，`has_guard=true`。消费徽章不存在时输出 `null`，不得用其它整数代替。

## 贵族档位

网页已观察到：剑士=1、骑士=2、领主=3、公爵=4、君王=5、帝皇=6。业务展示优先使用消息里的中文贵族名。

## 排除项

- 6111：普通用户进场，不欢迎、不打印。
- 1400：弹幕或系统句，不是进场。
- 1005、6200、6892、6210：只有完成独立 TAF 订阅验证和业务定义后，才能考虑接入。

6110 TAF 是当前唯一贵族进场业务来源。WebSocket 中观察到的任何进场 URI 都只能作为分析证据。
