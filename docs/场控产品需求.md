# 场控产品边界

## 产品定位

给主播或房管使用的 Windows 本机场控。一个命令行进程负责保活和日志，一个本地网页负责配置与启停，一个持久化 Chromium 负责登录、挂房和发送弹幕。

## 用户流程

```text
双击 run.bat
  → 打开本地控制台
  → 打开虎牙登录窗口并完成登录
  → 填房间、规则和文案
  → 明确打开需要的功能与“允许发送”
  → 启动场控
  → 停止挂房或关闭命令行退出
```

## 功能要求

| 模块 | 输入 | 规则 | 输出 |
| --- | --- | --- | --- |
| welcome | 贵族进场 | 贵族等级与消费等级达标，或拥有守护 | 欢迎弹幕 |
| gift_thank | 礼物 | 本包金额大于 0，且总价和单价达到门槛 | 礼物感谢 |
| guard_thank | 6540 TAF | 昵称、开通/升级动作和守护名称完整 | 守护感谢；不完整则仅记录诊断 |
| superfan_thank | 10079 / 2001231 TAF | 区分超粉/超粉PLUS，产品文案统一为开通 | 超粉感谢 |
| noble_thank | 1001 TAF | 读取动作、贵族名称和月份，并过滤其他房间 | 贵族感谢 |
| danmaku | 其它模块提交的文字 | 总开关、队列上限、最短间隔 | 页面输入框发送 |
| chat_control | 1400 用户弹幕 | 当前账号或启用的白名单 UID | `LU 开启/关闭 发送/欢迎/感谢` |

守护、超粉和贵族在 WebUI 合并显示为“非礼物感谢”，但仍使用独立开关和模板。各业务模块只能通过 danmaku 模块发送。发送失败记录日志且不自动重试，避免重复刷屏。

## 事件来源

- 生产业务事件只使用虎牙网页自身的 TAF `addTafListener` 结构化回调。
- 6110 贵族进场和 6501 礼物已完成页面 TAF 实证；1001 贵族、10079/2001231 超粉及 6540 守护的业务语义已有现场样本，TAF 监听已接入并需继续复验字段合同。
- WebSocket/JCE 只在 `validation/` 中用于发现候选 URI、保存原始样本和分析字段，不是业务备用通道。
- 新事件只有在 TAF 回调同时提供必需业务字段并通过严格校验后，才能进入领域事件总线。
- 守护开通只接受 6540 TAF 回调；历史 WebSocket 样本不触发业务。
- 6111 普通用户：不欢迎、不进入业务、不逐条打印。
- 1400 普通观众：可进入最近发言人候选，但正文不保存、不打印、不触发功能。
- 不使用 DOM 文案判断业务事件；6540 只检查 TAF 回调自身携带的结构化横幅文本。

## 安全默认值

- 初始房间为空。
- 所有欢迎、感谢和弹幕发送默认关闭。
- 登录态、日志和原始诊断消息只保存在本机且不入库。
- 公开示例不含当前账号 UID 或白名单；授权弹幕记录只在有界内存中保留。
- 用户必须主动开启“允许发送”。

## 当前不做

- 多账号、多房间、云端代挂
- 自动发现开播
- 连续礼物合并
- LU 状态查询、更多细分控制指令和趣味互动规则
- 绕过虎牙登录、验证码或平台限制
