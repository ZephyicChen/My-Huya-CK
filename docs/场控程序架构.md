# 场控程序架构

## 总览

```text
WebUI（固定状态栏 + 五个分页）
          │ HTTP
FastAPI 主进程
          │ 命令队列
Playwright 工人线程
  ├─ 页面 TAF：1400 弹幕 + 自动场控事件
  └─ 页面输入框：fill + click
          │
领域事件总线（去重）
  ├─ welcome
  ├─ gift_thank
  ├─ superfan_thank
  ├─ noble_thank
  └─ guard_thank（6540，默认关闭）
          │
danmaku 队列与发送间隔
```

1400 弹幕先经过独立的身份边界：

```text
1400 → UID / 昵称 / 正文标准化
     ├─ 普通观众：只更新最近发言人，不保存正文
     ├─ 当前账号：进入授权记录与 LU 一级指令
     └─ 白名单：按模块权限进入授权记录与 LU 一级指令
```

开发验证链路与产品隔离：

```text
validation/ 页面 WebSocket 探针
  → 拆信封、发现 URI、保存原始样本
  → 分析字段并验证 TAF 主动订阅
  → 确认字段合同和测试后，才把 TAF 回调加入产品
```

## 分层

| 层 | 目录 | 职责 |
| --- | --- | --- |
| WebUI | `web-src/`、`web/` | 表单、配置、启停；不理解消息协议 |
| API | `huya_ck/api/` | 配置与运行命令 |
| 平台 | `huya_ck/platform/` | 浏览器会话、消息监听、解码、权限状态、事件总线 |
| 功能 | `huya_ck/features/` | 筛选、模板、弹幕队列与发送 |

## 线程约束

同步 Playwright 只能由工人线程操作。工人运行时持续调用短 `wait_for_timeout`，用于分发页面消息回调，并在同一线程执行弹幕 `fill` 与 `click`。

FastAPI 请求只向工人命令队列投递登录、启动或停止指令，不直接持有 Page。

## 消息链路

### TAF 业务通道

`platform/official_taf.py` 在页面加载前注入桥接脚本，等待 `window.TTP.ready` 后注册：

- `addTafListener("6110", ...)`
- `addTafListener("6501", ...)`
- `addTafListener("6540", ...)`
- `addTafListener("1001", ...)`
- `addTafListener("1400", ...)`
- `addTafListener("10079", ...)`
- `addTafListener("2001231", ...)`

Python 暴露只读回调，将官方结构转换为 `enter`、`gift`、`guard_open`、`noble_open`、`superfan_open` 或 `chat_message`。1400 先经过当前账号/白名单授权，未授权正文不会保存或进入后续处理。6540 和 1400 的实际命名字段仍待现场实证；解析不到关键字段时不进入业务。

生产代码不得因为 TAF 未接入或暂时失效而回退到 WebSocket 触发业务。事件不可用时应明确记录通道状态并停止对应业务。

### WebSocket 验证工具

WebSocket 探针、JCE 信封解析、未知 URI 统计和原始包保存应收口在 `validation/`。它们的输出是候选证据，不能调用产品 `bus.emit`、功能 handler 或 danmaku。

### 去重与分发

`platform/bus.py` 对 TAF 领域事件去重并分发。礼物优先用支付单号生成事件 ID，避免官方回调重复处理。同人同种礼物的连击合并发生在 `gift_thank` 内部，不替代订单号去重。欢迎冷却记在 `welcome` 本场内存，不进入总线。规格见 [欢迎冷却与礼物合并设计.md](./欢迎冷却与礼物合并设计.md)。

## 发送

`danmaku.submit` 只入队；`danmaku.pump` 通过直播间输入框和发送按钮发出，并从成功点击发送后按 `interval_ms` 计算下一条的 CD。队列满时挤掉最旧消息；失败记录原因，不自动重试。

## 存活与恢复

- 登录过程中页面切换：选择最新仍打开的页面，TargetClosed 时重试一次。
- TAF attached / heartbeat 状态用于业务通道存活判断。
- 启动宽限后，通道断开或长时间静默会重新进入直播间。
- 停止挂房时关闭浏览器上下文，清空弹幕队列，并丢弃欢迎冷却表与未结算的礼物窗口。

## 已知缺口

- 守护 6540 TAF 的结构名、真实字段和与礼物/系统句的重复关系待现场验证。
- 1400 的页面 TAF 命名字段需真实直播间复验。
- 当前只有发送、欢迎、聚合感谢三组 LU 开关指令；状态查询、细分指令和趣味互动规则尚未定义。
- 页面选择器变化会影响弹幕发送。
