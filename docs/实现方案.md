# 场控实现方案

## 技术栈

| 项 | 实现 |
| --- | --- |
| 系统 | Windows 10 / 11 |
| 后端 | Python 3.10+、FastAPI、Uvicorn |
| 浏览器 | Playwright 持久化 Chromium |
| 前端 | Vue 3 + Vite，构建产物提交到 `web/` |
| 配置 | 本机 `config/app.json`；仓库示例 `config/app.example.json` |
| 日志 | stdout + `logs/huya_ck.log` 轮转文件 |

## 启动流程

`run.bat` 设置 UTF-8 和浏览器目录，调用 `ensure_env.py`：

1. 创建 `.venv`。
2. 安装 `requirements.txt`。
3. 下载 Chromium 到 `.playwright-browsers/`。
4. 运行 `python -m huya_ck`。

默认使用国内 PyPI 和 Playwright 镜像，可通过 `HUYA_CK_PIP_INDEX` 与 `PLAYWRIGHT_DOWNLOAD_HOST` 环境变量覆盖。

## 目录

```text
run.bat                 用户启动入口
tests.bat               产品测试
release-check.bat       发布前检查
ensure_env.py           本地环境准备
huya_ck/                后端与功能模块
web-src/                Vue 源码
web/                    已构建网页
config/app.example.json 安全示例配置
config/app.json         本机配置，不进入版本控制
docs/                   产品、架构、字段与发布文档
validation/             开发期探针，运行产品不依赖
tests/                  单元测试
```

## 事件源边界

- `huya_ck/` 只允许接入经过验证的页面 TAF 结构化回调。
- `validation/` 可以监听 WebSocket、拆 TAF/JCE 信封、统计 URI 和保存原始包。
- `validation/` 不得导入产品功能模块或触发弹幕；`huya_ck/` 不得把 WebSocket 帧送入领域事件总线。
- 新业务的合入门槛是：候选 URI 已发现、TAF 主动订阅已验证、字段合同已记录、离线与标准化测试已通过。
- TAF 不可用时对应业务明确不可用，不做 WebSocket 降级。

## 配置与模板

功能通过 registry 暴露 schema，WebUI 根据 schema 画表单。模板支持 `{变量}` 和 `{A|B|字面量}`，从左到右选择第一个非空值。

WebUI 使用固定核心状态栏与五个分页：总览、自动场控、远程控制、趣味互动、运行记录。远程控制随挂房和 1400 监听运行，没有独立总开关；严格匹配 `LU 开启/关闭 发送/欢迎/感谢`，白名单按模块授权。趣味互动在规则确定前保持不可用。

内置默认值和 `config/app.example.json` 全部关闭。用户设置写入已忽略的 `config/app.json`，不得加入版本控制。

## 测试

`tests.bat` 运行产品单元测试。`release-check.bat` 额外运行 `git diff --check` 并展示待提交文件。

`validation/event-captures/` 不入库；其中的 WebSocket/JCE 回放只验证分析工具和字段研究，不代表该 URI 已获准进入产品业务。

## 发布约束

- 不提交登录 Profile、日志、原始消息、虚拟环境和 Chromium。
- 前端源码变化后必须重新构建 `web/`。
- 不在发布脚本中自动推送或创建 GitHub Release。
- 正式版采用 MIT License；发布前仍需确认日志、登录态和本机配置未进入版本控制。
