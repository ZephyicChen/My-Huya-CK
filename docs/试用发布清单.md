# 试用发布清单

## 自动检查

运行：

```bat
release-check.bat
```

确认测试通过、`git diff --check` 无错误，并查看脚本打印的 Git 变更。

TAF-only 路线整改完成前不得发布下一试用版。自动测试还必须证明任意 WebSocket 帧不能进入产品事件总线或触发弹幕。

## 人工检查

- [ ] `config/app.json` 未被 Git 跟踪，`config/app.example.json` 的房间为空且所有 `enabled` 为 `false`
- [ ] 未提交 `playwright-profile/`、`logs/`、原始消息、`.venv/` 或 Chromium
- [ ] 若修改过 `web-src/`，已经执行 `npm run build` 并提交 `web/`
- [ ] README 的安装步骤在一台新 Windows 设备验证过
- [ ] 登录、官方 1001/6110/6501/6540/10079/2001231 接入、停止挂房各跑一次
- [ ] 产品运行时未挂接 WebSocket 业务监听，`validation/` 之外没有原始帧驱动业务
- [ ] 守护 TAF 未验证时明确告知：可以配置和启用，但识别不到完整字段时不会发送，也不会回退到 WebSocket
- [ ] 用低于和达到门槛的礼物各验证一次
- [ ] 用满足和不满足条件的贵族进场各验证一次
- [ ] 明确告知当前仍不建议在无人观察时长期运行
- [ ] 根目录包含完整 MIT `LICENSE`

## 建议 GitHub Release 内容

- 标签：`v1.0.0`
- 标题：`v1.0.0 首个正式版`
- 说明引用 `CHANGELOG.md`
- 附上已知限制和反馈要求

## 反馈信息

让试用者提供：

1. Windows 与 Python 版本。
2. 出错时间、功能和预期结果。
3. 对应时间附近的少量日志，先遮掉房间号、昵称和 UID。
4. 是否显示直播间窗口、是否已经登录。

不要让试用者上传完整 `playwright-profile/` 或整份原始消息目录。
